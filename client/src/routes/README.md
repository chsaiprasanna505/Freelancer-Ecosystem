# Freelancer Ecosystem Platform 🚀

A full-stack freelancing platform that connects clients and freelancers. 
Clients can post jobs, review applications, and manage projects, while freelancers can explore jobs and submit proposals.

---

## 📌 Project Overview

Freelancer Ecosystem is a MERN stack web application developed to simplify the hiring process between clients and freelancers.

The platform provides role-based dashboards where users can manage their activities efficiently.

---

## ✨ Features

### 🔐 Authentication
- User registration and login
- JWT-based authentication
- Protected routes
- Role-based access control

### 👨‍💼 Client Features
- Client dashboard
- Post new jobs
- View posted jobs
- Receive freelancer applications
- Accept or reject applications
- Manage projects

### 👨‍💻 Freelancer Features
- Freelancer dashboard
- Browse available jobs
- View job details
- Apply for jobs
- Track applications

### 📊 Dashboard Features
- Statistics cards
- Recent activities
- Progress tracking
- Professional dark UI design
